PROJET : CompteurAndroid
Langage : Kotlin
Modele : Empty Views Activity
SDK minimal : API 24

OUVERTURE DU PROJET
1. Ouvrir Android Studio.
2. File > Open... puis selectionner le dossier CompteurAndroid.
3. Attendre la synchronisation Gradle.
4. Lancer l'application sur un emulateur (API 24 ou superieur).

FICHIERS PRINCIPAUX
- app/src/main/java/com/example/compteurandroid/MainActivity.kt
- app/src/main/res/layout/activity_main.xml
- app/src/main/res/values/strings.xml
- app/src/main/res/values/colors.xml
